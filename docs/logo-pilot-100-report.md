## Conclusion

The V2 entity-aware pipeline substantially reduces false positives compared with V1, but the 100-organization pilot still shows 3 false positives among 58 auto-accepted assets (observed precision 94.8%). Therefore `present` should not yet be published without another heuristic hardening pass. The dominant remaining error classes are event logos, sponsor logos without explicit sponsor context, and header/background photos that inherit strong page identity.

Recommended next changes: add negative event/regatta vocabulary, require candidate-specific identity evidence for generic `logo` filenames, prefer explicit site-identity/logo contexts over equal-scoring background/header images, and downgrade very wide photo/header assets.
